# Freebies Directory - Free KDP & Book Templates

A static directory of **free** KDP and book publishing templates: interior layouts, cover templates, copyright pages, and series bibles.

Built and maintained by [Dylan Asdale](https://dylanasdale.github.io) — credit: **Asdale Dynamics, LLC**.

## What's inside

Each listing includes:

- **Cost** - always free or free-tier
- **Platform** - where the template lives
- **Steps** - plain-English, numbered instructions
- **Official link** - direct to the publisher/platform page (no affiliate links)

Categories:

- Interior layouts
- Cover templates
- Copyright pages
- Series bibles

## How to use

Open `index.html` in any browser. Use the search box to filter by title, category, platform, or steps. Click a category chip to narrow results. All links open the official source page in a new tab.

## No affiliate links

Every link in this directory points to the official platform or publisher page. No affiliate links, no tracking, no personal data.
